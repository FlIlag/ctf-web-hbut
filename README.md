## 📋 仓库结构

```
📁 代码审计/          — 各漏洞类型的代码审计思路与案例
  ├── java/
  └── php/
      ├── csrf/       — CSRF 绕过
      ├── rce/        — 远程代码/命令执行
      ├── sql/        — SQL 注入
      ├── ssrf/       — SSRF 服务端请求伪造
      ├── xss/        — 跨站脚本
      ├── xxe/        — XML 外部实体注入
      ├── 其他漏洞/   — 变量覆盖、重装漏洞
      ├── 文件上传/   — 文件上传绕过
      ├── 文件包含/   — LFI/RFI
      ├── 文件安全/   — 文件操作函数
      ├── 未授权访问/ — 权限校验绕过
      └── 逻辑漏洞审计/— 业务逻辑漏洞

📁 内网渗透/          — 内网渗透技巧
  ├── 隧道/          — 代理、隧道搭建
  └── 内网存活主机扫描

📁 常规web/           — CTF 常规 Web 题型
  ├── 一句话/        — 一句话木马集合
  ├── 业务逻辑漏洞的场景收集/
  ├── 向量利用方式/  — HTTP 攻击向量、Payload
  ├── 小知识点/
  ├── 常用工具教程/  — 工具使用指南
  ├── 拿shell后操作/ — 提权、信息收集
  ├── 特殊漏洞/      — 各端口/服务漏洞
  └── 特殊环境/      — CMS、SMB 等环境

📁 流量分析/          —  Webshell 流量分析
  ├── 漏洞特征/      — 漏洞攻击流量
  └── 特征/          — 工具流量特征(冰蝎/哥斯拉/菜刀/蚁剑)
```
