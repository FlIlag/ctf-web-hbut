# 常见漏洞关键字

## SQL 注入
- `select` `insert` `update` `delete` `mysql_query` `mysqli` `mysqli_query`
- `PDO` `query()` `prepare()` `exec()`
- `where` `order by` `limit` — 注意：order by/limit 后的参数无法预编译
- 搜索关键词: `$_GET` `$_POST` `$_REQUEST` `$_COOKIE` 直接拼接 SQL

## 文件上传
- `$_FILES` `type="file"` `上传` `move_uploaded_file()`
- `upload` `file_put_contents()` `fwrite()` `fputs()`
- 搜索: `enctype="multipart/form-data"` `$_FILES`
- 检查: 白名单/黑名单验证、内容检查、二次渲染

## XSS 跨站
- `print` `print_r` `echo` `sprintf` `die` `var_dump` `var_export`
- `printf` `vprintf` `write` `out.print` `response.write`
- 反射型: 参数直接输出到页面
- 存储型: 写入数据库后在其他页面展示

## 文件包含
- `include` `include_once` `require` `require_once`
- `file_get_contents()` `readfile()` `file()` `fgets()` `fread()`
- 搜索: `$_GET['file']` `$_GET['page']` `$_GET['include']`

- `create_function()` `array_map()` `usort()` `uasort()` `uksort()`
- 搜索: `$_GET['code']` `$_POST['code']` 动态函数调用

## 命令执行

## 审计思路

1. **关键字搜索法**
   - 搜索危险函数定位代码位置 → 追踪参数来源 → 判断是否可控 → 验证过滤

2. **功能点分析法**
   - 浏览功能 → 抓包分析 → 搜索对应处理代码 → 追踪数据流

3. **MVC/框架审计**
   - 关注 Controller 层的参数接收 → Model 层的执行 → View 层的输出
   - 重点查看路由配置文件，确定 URL 与控制器方法的对应关系
   - 关注框架自带的过滤和转义机制是否被绕过

4. **常见关注点**
   - 危险函数前是否有过滤/转义
   - 过滤是否可绕过（黑名单缺失、正则不严谨）
   - 用户可控数据是否进入危险函数
   - 权限校验是否完整
